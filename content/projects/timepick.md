网页、文档、图片、视频散落在浏览器收藏夹、聊天记录和本地文件夹里，想用的时候找不到。拾光（TimePick）把这些资源收进一个统一的个人知识库：收藏、分类、检索一条龙，配灵感速记与待办事项，让"存下来"的东西真的能被再次找到。

## 它解决什么问题

收藏夹的通病是"存的时候随手一扔，找的时候大海捞针"。拾光用 AI 智能分类替用户做归档动作，再用全文搜索兜底；灵感速记和待办事项把"以后再看"的链接变成真正会被消化的任务，而不是越堆越长的列表。

## 技术实现

- **资源管理**：网页、文档、图片、视频统一收藏、分类与检索，一套界面管理所有数字资源。
- **AI 智能分类**：自动识别资源类型并归类，减少手工整理成本。
- **全文搜索**：快速定位已存内容，不用逐个点开翻找。
- **灵感与待办**：快速记录想法和灵感；管理待尝试链接和任务。
- **技术栈**：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui，Supabase 作为后端；站点已上线 shiguang.app，源码在 GitHub 开源。
